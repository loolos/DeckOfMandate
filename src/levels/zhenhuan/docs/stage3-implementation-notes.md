## 六、平衡观察（自动模拟，仅供参考）

- 随机打法 400 局：胜率约 15%。“优先打能解事件 / 推进移花接木的牌”的简单打法 400 局：胜率约 49%，完美结局约 1.5%。
- 输得最多的是第三幕疑点到 5。修行身份每回合只能打 1 张，引驾 → 偶遇要连着两回合摸到对的牌。如果实际玩下来太紧，可以考虑以下几种调整：
  - 第三幕改成抓 3 打 1；
  - 牌库里多放 1 张禅语修身；
  - 疑点起始改为 0。
