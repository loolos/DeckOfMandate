# 甄嬛传第三关 · 插画任务

这份文件是一组插画任务，给 ChatGPT 逐张生成用，一共 60 段 prompt。文件分四部分：一、统一设定；二、第三关补充设定；三、出图格式；四、逐张 prompt。前三部分每张图都要遵守；第四部分每段以编号开头，按顺序每次只画一段。

## 一、统一设定

```text
接下来请你为一款宫廷题材卡牌游戏逐张生成插画。以下统一设定，之后每张图都必须遵守。

【题材】中国清代雍正年间的后宫，原创故事。不要参考任何影视剧剧照，不要模仿任何真实演员或真实人物的样貌。

【画风】国风平涂插画：清晰的墨色轮廓线，平涂色块加少量柔和渐变阴影，局部点缀工笔装饰纹样（衣料暗纹、窗棂、屏风花鸟）。造型简洁，主体轮廓在缩小到 200 像素宽时仍一眼可认。不要照片写实、不要 3D 渲染、不要日式动漫风。

【色调】整体偏沉静的宫廷色：朱红、黛青、象牙白、暗金，饱和度中等偏低，带一点旧绢纸质感。

【人物】人物以背影、侧影、半身或局部（手、衣袖、发饰）为主；必须出现正脸时，五官极简、面部留白，不画可辨认的具体长相。人物靠服色和标志物区分，固定如下：
- 主角（下称“小主”）：浅碧色或月白色宫装，发间一支白玉簪，常配杏花或竹影。
- 皇后：深青底凤纹宫装，金色凤钗，端庄。
- 华妃：华贵的满式旗装（金红或玫红色锦缎袍服，立领大襟，衣襟和袖口镶宽花边），头戴高耸的旗头（两把头），旗头正中簪一朵大红牡丹，两侧缀满珠翠和垂下的长流苏，脚穿花盆底鞋；不戴护甲。气势凌厉，鎏金香炉是她的标志。
- 太后：深赭或酱褐色，素净，手持佛珠。
- 眉庄：以紫色调为主的宫装（丁香紫、青莲紫，可配浅紫或银白镶边），端庄刚直、坦荡有主见，腰背挺直、步态沉稳，常在明亮处。
- 陵容：淡粉或浅黄素色宫装，纤弱怯懦、心思深藏，常低头含胸、半隐在人后或阴影里，腰间挂一只精巧的香囊。
- 槿汐（第二、三关出现）：深蓝灰色掌事姑姑服，发髻整齐，常持钥匙串或托盘。
- 小允子（碎玉轩的小太监）：青灰色小太监服，机灵忠厚，面部光洁、没有胡子。
- 流朱（小主的贴身宫女）：浅粉色宫女服，伶俐忠心。
- 温太医：青色官服，背药箱。
- 自称“果郡王”的男子（实为微服的皇上）：月白或天青素净常服，腰间系一条明黄络子，气度不凡，只画侧影或背影，不画正脸。
- 端妃：素色衣裳外罩深色斗篷，清瘦病弱，常捧暖炉。
- 曹贵人：暗紫色宫装（深沉的茄紫或绛紫，比眉庄的丁香紫暗得多，素净少饰），温婉而精明。
- 余莺儿：艳丽的桃红宫装，张扬。
- 太监：深色太监服、帽子，面部光洁、没有胡子，以剪影为主。
- 皇上：一律不正面出现，只用明黄色衣角、龙纹袖口或远处的明黄灯笼暗示。

【文字】画面任何位置都不得出现可读文字：匾额、对联、圣旨、书页、灯笼上只能是抽象纹样或留白。

【硬性限制】不出现血迹、伤口、暴力特写，危险用暗示表达（翻倒的碗、变黑的银针、落花）。不出现现代物件。不加边框、标题或水印。

【构图】主体居中，四边留出约 8% 的安全边距，之后会裁切并加圆角。

【比例】除非我另行说明，一律横版 4:3。如果只能输出 3:2 横版，请把主体集中在中间，左右两侧各约 12% 只放可以被裁掉的背景。
```

## 二、第三关补充设定

```text
这一组是第三关的图。下面是本关在统一设定之外的补充，每张都要同时遵守。

【本关故事】华妃已倒，小主晋为莞嫔。皇后表面温和，暗中算计。后来小主自请出宫，到京郊山寺甘露寺带发修行，又被赶去更偏僻的后山凌云峰，最后设法回宫。第一幕在宫中，第二幕在甘露寺，第三幕在凌云峰和回宫之前。

【小主在本关的样子】
- 宫中（第一幕）：仍是浅碧或月白色宫装、白玉簪。位分高了，衣饰比从前讲究一些（衣缘多一道刺绣，发间多一两件珠饰），但依旧清雅、不张扬。后半段有孕，宽松的衣裳下微微隆起。
- 寺中与山上（第二、三幕）：带发修行，头发简单挽起，只插一支木簪；穿月白或浅灰的修行素衣（宽袖、交领的粗布长衣），腰间系一条褪了色的浅碧布带。这条布带是她在寺中的标志，每张都要保留。双手常因劳作发红。

【本关新出场的人物】
- 果郡王（允礼）：这一关的果郡王是真正的王爷，和统一设定里那位“自称果郡王的男子（微服的皇上）”不是同一个人，身上不要有任何明黄色。他穿石青色的郡王常服（不用天水碧，免得和小主的浅碧混在一起），冷天外罩一件深青色披风，腰间悬一支白玉笛，笛尾垂一条朱红穗子。身形修长，温润潇洒。可以画侧脸，五官依旧极简。
- 阿晋：果郡王的随从小厮，深褐色短打，利落机灵。
- 齐妃：枣红色宫装，头上金饰堆得满满、略显俗气，身形微丰，神情常带着不服气。
- 三阿哥：齐妃的儿子，十来岁的皇子，宝蓝小袍，捧着书本，神情发蔫。
- 祺贵人：玫粉色宫装，满头新簪的珠翠和一朵大绒花，年轻娇纵，下巴微扬。
- 敬妃：秋香色宫装，温厚安静，常拿着针线或绣绷。
- 欣贵人：宝蓝色宫装，爽朗泼辣，说话手势大，笑得开怀。
- 剪秋：皇后的掌事宫女，墨绿色宫女服，低眉稳重，常捧托盘或食盒。
- 苏培盛：御前总管太监，深色太监服，手持拂尘，面部光洁、没有胡子。
- 胧月：小主的女儿，襁褓里的婴儿，或画像上胖乎乎的小女孩。
- 静岸师太：甘露寺住持，褐黄色僧袍，年长慈和，手持念珠。
- 静白：甘露寺管事的尼姑，灰黑色僧衣，身形干瘦，腰间挂一串钥匙，常叉腰或指指点点。
- 莫言：寺里的尼姑，灰布僧衣，挽着袖子，结实寡言。
- 其他尼姑：灰色僧衣，以剪影为主。
- 槿汐：在寺中和山上陪小主一起修行，换成深蓝灰的修行粗布衣，发髻用灰布包起，不再拿钥匙串和账册。

【修行期间的穿着（第二、三幕，务必遵守）】甘露寺和凌云峰这段日子，小主和身边的槿汐都在修行，一律穿修行的素色粗布衣：不穿宫装、宫女服，不戴珠翠、旗头、护甲，不用华丽的刺绣和锦缎。宫里来的人（眉庄、温太医、皇后派来的人）照旧穿宫里的衣裳，正好和她们形成对比。凡是 prompt 里写了“修行期间”的，都按这一条画。

【本关场景】
- 宫中：碎玉轩（竹子、海棠）、景仁宫（深青与暗金，总有一线冷光）、延庆殿（帘幕低垂、药炉）、咸福宫（温暖、满是绣品）、御花园、桐花台（高台、桐花）。
- 甘露寺：山间古寺，灰瓦黄墙，大殿长明灯，柴房、井台、水缸，冬天积雪。
- 凌云峰：后山更高更偏的几间小屋，松林、山路、月光、风雪。
- 清凉台：果郡王的别院，温暖雅致。

【皇后】本关的皇后事件里，皇后往往不露面，用她的深青凤纹衣角、金凤钗，或剪秋捧来的东西代替。她的“好意”要画得温和体面，同时留一处叫人不安的小细节。

【色调】宫中的好事偏暖亮，宫中的麻烦偏冷暗；齐妃、祺贵人惹出的事偏枣红、玫粉；皇后的事偏深青、暗金。甘露寺和凌云峰整体素淡灰青，好事带一点烛火暖光，坏事偏雪色冷灰。

【剧情图】编号以 S 开头的是剧情图，画面可以比普通事件更有叙事感、人物更多。有几张剧情之后会有不同走向，画面只画做决定之前的那一刻，不表现任何一种结局。
```

## 三、出图格式

- 每次只生成一张图，对应一段 prompt。不要一次画多张，也不要把几张拼在同一幅图里。
- 比例：手牌（C 开头）、事件（E 开头）、剧情（S 开头）一律横版 4:3；背景（B3）是横版 16:9，它的 prompt 里另有说明。如果只能输出 3:2 横版，把主体集中在中间，左右两侧各约 12% 只放可以裁掉的背景。
- 构图：主体居中，四边留出约 8% 的安全边距，之后会裁切并加圆角。
- 画面里不出现任何可读文字，也不要边框、标题、水印。图片下方不要加白边、说明条或文件名。
- 编号只写在你回复的文字里：每画完一张，回复一行“已完成：编号（还剩 N 张）”，例如“已完成：C09（还剩 59 张）”。
- 按第四部分的顺序一段一段往下画。全部画完后回复“全部完成”。
