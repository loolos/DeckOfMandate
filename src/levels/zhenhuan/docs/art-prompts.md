# 甄嬛传 · ChatGPT 出图 Prompt

49 张配图（手牌 8、事件 23、剧情与考验 16、背景 2）的出图 prompt，用于在 ChatGPT 里逐张生成。比例、尺寸与入库方式见 [art-spec.md](./art-spec.md)。

## 使用方法

在同一个 ChatGPT 对话里先发「风格设定」，再一条消息发一张图的 prompt；下载后按编号重命名，上传回仓库。

1. **新开一个对话，先发「风格设定」整段。** 这条只让它记住规则，回复「明白」即可，不出图。
2. **先试做 3 张：C01 仪容整肃、E22 一丈红、B1 第一关背景。** 满意后挑一张画风最好的当参考图；以后每开一个新对话，先上传这张参考图，并说「之后的图都保持与这张图一致的画风」。
3. **一条消息只发一张图的 prompt。** 每段 prompt 已经写好比例和编号，直接整段复制。一次发多张，画风和构图都会变差。
4. **大约每 8–10 张开一个新对话**，重新发风格设定和参考图。对话太长画风会慢慢跑偏。
5. **下载后按编号重命名**，例如 C01.png、E22.png、B1.png。ChatGPT 下载的文件名是随机的，编号写在每段 prompt 的第一行，ChatGPT 出图后也会提醒你。
6. **比例不必强求。** 手牌和事件要 4:3 横版，背景要 16:9。ChatGPT 若只给 3:2 横版也可以，导入时会居中裁切，所以 prompt 都要求主体居中。
7. **交回仓库：** 每个编号只传选定的一张，上传到 `art-inbox/` 文件夹。改成游戏 id、裁切和压缩在导入时处理；图片下方若带有“文件 xx.png”之类的白条，导入时会自动截掉（`scripts/trimArtBar.mjs`）。

## 风格设定（第一条消息）

每个新对话的第一条消息都发这段，整段复制。人物靠服色和标志物区分、不画可辨认的脸，这样既能保持多张图一致，也避开演员肖像。

```text
接下来我会请你为一款宫廷题材卡牌游戏逐张生成插画。请先记住以下统一设定，之后每张图都必须遵守。本条消息不需要出图，回复“明白”即可。

【题材】中国清代雍正年间的后宫，原创故事。不要参考任何影视剧剧照，不要模仿任何真实演员或真实人物的样貌。

【画风】国风平涂插画：清晰的墨色轮廓线，平涂色块加少量柔和渐变阴影，局部点缀工笔装饰纹样（衣料暗纹、窗棂、屏风花鸟）。造型简洁，主体轮廓在缩小到 200 像素宽时仍一眼可认。不要照片写实、不要 3D 渲染、不要日式动漫风。

【色调】整体偏沉静的宫廷色：朱红、黛青、象牙白、暗金，饱和度中等偏低，带一点旧绢纸质感。

【人物】人物以背影、侧影、半身或局部（手、衣袖、发饰）为主；必须出现正脸时，五官极简、面部留白，不画可辨认的具体长相。人物靠服色和标志物区分，固定如下：
- 主角（下称“小主”）：浅碧色或月白色宫装，发间一支白玉簪，常配杏花或竹影。
- 皇后：深青底凤纹宫装，金色凤钗，端庄。
- 华妃：华贵的满式旗装（金红或玫红色锦缎袍服，立领大襟，衣襟和袖口镶宽花边），头戴高耸的旗头（两把头），旗头正中簪一朵大红牡丹，两侧缀满珠翠和垂下的长流苏，脚穿花盆底鞋；不戴护甲。气势凌厉，鎏金香炉是她的标志。
- 太后：深赭或酱褐色，素净，手持佛珠。
- 眉庄：以紫色调为主的宫装（丁香紫、青莲紫，可配浅紫或银白镶边），端庄刚直、坦荡有主见，腰背挺直、步态沉稳，常在明亮处。
- 陵容：淡粉或浅黄素色宫装，纤弱怯懦、心思深藏，常低头含胸、半隐在人后或阴影里，腰间挂一只精巧的香囊。
- 槿汐（仅第二关出现）：深蓝灰色掌事姑姑服，发髻整齐，常持钥匙串或托盘。
- 小允子（碎玉轩的小太监）：青灰色小太监服，机灵忠厚，面部光洁、没有胡子。
- 流朱（小主的贴身宫女）：浅粉色宫女服，伶俐忠心。
- 温太医：青色官服，背药箱。
- 自称“果郡王”的男子（实为微服的皇上）：月白或天青素净常服，腰间系一条明黄络子，气度不凡，只画侧影或背影，不画正脸。
- 端妃：素色衣裳外罩深色斗篷，清瘦病弱，常捧暖炉。
- 曹贵人：暗紫色宫装（深沉的茄紫或绛紫，比眉庄的丁香紫暗得多，素净少饰），温婉而精明。
- 余莺儿：艳丽的桃红宫装，张扬。
- 太监：深色太监服、帽子，面部光洁、没有胡子，以剪影为主。
- 皇上：一律不正面出现，只用明黄色衣角、龙纹袖口或远处的明黄灯笼暗示。

【文字】画面任何位置都不得出现可读文字：匾额、对联、圣旨、书页、灯笼上只能是抽象纹样或留白。

【硬性限制】不出现血迹、伤口、暴力特写，危险用暗示表达（翻倒的碗、变黑的银针、落花）。不出现现代物件。不加边框、标题或水印。

【构图】主体居中，四边留出约 8% 的安全边距，之后会裁切并加圆角。

【比例】除非我另行说明，一律横版 4:3。如果只能输出 3:2 横版，请把主体集中在中间，左右两侧各约 12% 只放可以被裁掉的背景。

【命名】每条消息开头有一个编号（如 C01、E22、B1）。出图后请在图片下方写一行“文件名：编号.png”，提醒我保存时用这个名字。
```
