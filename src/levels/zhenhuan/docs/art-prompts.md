这次只画第三关「青灯凤阙」的 62 张图：手牌 C09–C18（其中 C16–C18 是三张旧手牌的寺中版）、事件 E24–E56、剧情 S17–S32（含 S27b、S27c）、背景 B3。设定、出图格式和全部 prompt 都在 [art-prompts-stage3.md](./art-prompts-stage3.md)，ChatGPT 直接从仓库读这份文件。前两关的 49 张已经入库，不再改动，它们的 prompt 存档在本文末尾。比例、尺寸与入库方式见 [art-spec.md](./art-spec.md)。

第三关沿用的旧图不用重画：仪容整肃、谨言慎行、温太医相助、收拢人心、静观其变、眉庄相助、陵容相助、槿汐相助 8 张手牌（第一幕用；后三张在第二、三幕换成寺中版），中宫垂青、太后垂询、请脉报喜、蜚语盈廊、内务府刁难、仪态微瑕 6 个事件，以及剧情凤鸾承恩。

## 使用方法

1. **在 ChatGPT 里连上 GitHub**，授权它读取 `loolos/DeckOfMandate`。
2. **新开一个对话，发下面「发给 ChatGPT 的消息」。** 它会先读文件，回复「已读完，共 62 段」，然后建好定时任务，之后每 15 分钟画一张。
3. **第一张出来先看画风。** 满意的话把它存下来当参考图；不满意就停掉任务，调整后重来。
4. **画完关掉任务。** 每张图它会回复「已完成：编号（还剩 N 张）」，全部画完会说「全部完成」。
5. **画风跑偏就换对话。** 对话太长画风会慢慢跑偏。如果后面的图明显不像前面的，就停掉任务，新开对话再发一次这段消息，同时上传参考图并说「之后的图都保持与这张图一致的画风，从编号 X 开始」。
6. **下载后按编号重命名**，例如 C09.png、E24.png、B3.png。ChatGPT 下载的文件名是随机的，编号写在它每次回复的文字里，不会画进图里。
7. **交回仓库：** 每个编号只传选定的一张，上传到 `art-inbox/` 文件夹。改成游戏 id、裁切和压缩在导入时处理；万一图片下方还是带了一条白边或文字，导入时会自动截掉（`scripts/trimArtBar.mjs`）。

## 发给 ChatGPT 的消息

```text
请通过 GitHub 连接读取仓库 loolos/DeckOfMandate 里的文件 src/levels/zhenhuan/docs/art-prompts-stage3.md（main 分支）。这是一组插画任务，一共 62 段 prompt。

先完整读一遍文件里的「一、统一设定」「二、第三关补充设定」「三、出图格式」，之后每张图都必须遵守。现在先不要画图，读完回复“已读完，共 62 段”。

然后请建一个定时任务，每 15 分钟执行一次。每次执行时，按文件「四、逐张 prompt」的顺序，找出第一段还没有生成的 prompt，只画这一张，并按「三、出图格式」回复“已完成：编号（还剩 N 张）”。如果某次读不到仓库，就用你已经读过的内容继续。全部生成完后回复“全部完成”，并提醒我关闭这个任务。
```
